# Навык: sync-agents — проекции канона для агентов

**Инвариант:** один экзокортекс — много агентов. Канон навыков живёт в `tools/skills/` (agent-neutral SKILL.md). Всё, что видят конкретные агенты (`.claude/`, `.claude-plugin/`, `AGENTS.md`, `.cursor/`), — **генерируемые проекции**: их не редактируют руками, их перегенерирует этот навык. Правила маппинга — `.exocortex/projections/README.md`.

## Вход

- `.exocortex/manifest.yaml`: `agents:` (список) + `tier:`.
- `tools/skills/*/SKILL.md` (+ ресурсы навыков) — канон.
- `tools/mcp/*` — канон MCP-серверов (для проекции в конфиг агента; см. ветку `codex`).

## Шаги

1. **Манифест.** Нет `agents:` → спроси (AskUserQuestion, multi-select: claude-code / cowork / cursor / codex / другой) и запиши.
2. **Фильтр по tier (DM-EXO-13).** Каждый канон-навык несёт `tier: base | pro | team | entrepreneur` — ступень, с которой он появляется.
   - Ступень навыка **выше** текущей → в проекцию не попадает.
   - **Поля нет** → проецируй как `base`, но **скажи об этом в отчёте**: «навык `<name>` без `tier:` — принят как base». Не молчи: молчание превращает контракт в мёртвую букву.
   - **Навык уже стоял, а ступень понизилась** → не удаляй, **заморозь** (шаг 2-bis).
2-bis. **Заморозка при понижении ступени (DM-EXO-13 §4).** Навык выше текущей ступени, который **уже присутствует** в проекциях, продолжает работать той версией, что стоит, — но перестаёт обновляться.
   - Во frontmatter канона и проекций добавь: `frozen_from_tier: <его ступень>`, `frozen_at: <YYYY-MM-DD>`, `frozen_seed_version: <version из .claude-plugin/plugin.json>`.
   - Сразу после frontmatter — врезка одной строкой: `> ⚠ Замороженная версия навыка ступени <tier> от <дата>. Работает, но обновления не приходят — ступень инстанса ниже.`
   - Навык **выходит из seed-managed**: `/update-exocortex` его не трогает и не удаляет.
   - Из `plugin.json` и проекций **не убирай** — он работает, значит должен быть виден.
   - **Разморозка** (ступень поднялась): сними три поля и врезку, возьми свежую версию из канона. Если пользователь правил замороженный навык руками — **покажи расхождение и спроси**, не затирай молча.
   - Данные (`boks/`, `operation/sessions/`, карточки, профиль) не трогаются никогда.
3. **Проекции по агентам:**
   - `claude-code`: скопируй каждый канон-навык в `.claude/skills/<name>/` (SKILL.md + ресурсы), добавив во frontmatter `x_generated: "sync-agents — правь канон в tools/skills/"`; обнови `.claude/commands/*.md` (тонкие вызовы навыков); hooks (`.claude/hooks/`) не трогай — они seed-managed.
   - `cowork`: перегенерируй `.claude-plugin/plugin.json` — список путей `.claude/skills/*` (кроме user-level `init-exocortex`) + `"commands": ".claude/commands"`. Это единственный источник реестра навыков Cowork — новый навык появляется в Cowork только после перегенерации (не редактируй plugin.json руками). После правки — пересобери ZIP в `distributions/` (см. `distributions/README.md`).
   - `codex`: полноценная project-scoped проекция (DM-EXO-10). (а) `.codex/skills/<name>/` — скопируй каждый канон-навык (SKILL.md + ресурсы, формат Codex-Skills == канон), добавив `x_generated`; `init-exocortex` (user-level) исключи; гейт по `tier:` тот же. Идемпотентно: remove+copy. (б) `.codex/config.toml` — секция `[mcp_servers.*]` из канона `tools/mcp/*` (TOML; конвертируй из JSON `mcpServers`, если канон в JSON; пустой канон → пустая/отсутствующая секция). (в) `AGENTS.md` — тонкий вход (Codex читает нативно): карта зон + «навыки доступны из `.codex/skills/` или `$<skill>`; MCP — `.codex/config.toml`; канон — `tools/skills/`».
   - `cursor` / другой: убедись, что `AGENTS.md` существует и актуален (карта зон + список навыков + правило «канон в tools/skills»); для cursor дополнительно `.cursor/rules` по шаблону из `.exocortex/projections/` (если задан).
4. **Тонкие входы:** проверь `CLAUDE.md` и `AGENTS.md` — заголовок-маркер `generated by sync-agents`, карта зон, список навыков соответствуют канону. **Блок `<!-- projects-map:start/end -->` переноси как есть — он user-owned.**
5. **Идемпотентность:** повторный прогон без изменений канона не создаёт diff. Ничего не пиши в user-owned зоны (About-Me, concepts, operation, sources, projects, areas).
6. **Отчёт:** таблица агент → сгенерировано/без изменений; отдельными строками — навыки без `tier:` (приняты как base) и замороженные (`frozen_from_tier`, дата). Напомни закоммитить. Удаление агента из `agents:` → предложи удалить его проекцию (только с подтверждением).

## Выход

Актуальные проекции для всех агентов манифеста; репозиторий готов к работе из любого из них.
