# Фаза CLOSE — закрыть сессию

Роутер и инварианты — [SKILL.md](SKILL.md).

## CLOSE-0. Решения на месте

Проверь секцию `## Решения зафиксированы` атома: всё, что было решено за сессию, записано
утвердительными фразами со следствиями (MID-1). Что-то принималось и не записано — запиши
**сейчас**, до итога. Итог, за которым не стоят решения, через неделю не восстанавливается.

## CLOSE-1. Сессия и проект

(AskUserQuestion) Открытая сессия одна — предложи её; иначе выбор из активных проектов.

## CLOSE-2. Итог

(короткий текст): что сделано · следующий шаг.

## CLOSE-3. Статус

(AskUserQuestion): `продолжу` (проект `active`) / `готово` (проект `done`) / `отложено`
(проект `paused`).

## CLOSE-4. Консолидация находок

- Родились находки или различения — предложи прогнать их через `/review-concepts`; карточка
  получает `source_session:` с `session_id` этой сессии.
- Проставь в атоме `produced:` — список рождённых карточек (или оставь `[]`).

## CLOSE-5. Финализация атома

Атома нет — создай задним числом из шаблона `operation/sessions/README.md`.

- **TL;DR — одной строкой как ответ на «Цель»**: достигнута, частично или нет; эмодзи несёт исход.
  Эта же строка пойдёт в день.
- Секции: `Создано / Обновлено` (wikilinks) · `Решения зафиксированы` · `Хронология`
  (строка `- **ЧЧ:ММ CLOSE:** <итог>`) · `Следующий шаг`.
- `## 🔁 Команда для продолжения` — заполни, если работа продолжится в новом чате (формат —
  MID-5: строка 0 несёт сессию, **строка 1 — проект**); иначе убери секцию.
- Frontmatter: `Status:` → `"🟢 Выполнена"` / `"⚪ Отложена"` / `"🔴 Не сработало"`; `Active: false`.

## CLOSE-6. Записи

- **Карточка проекта**, блок `sessions`:

  ```markdown
  ### <ГГГГ-ММ-ДД ЧЧ:ММ> — итог
  - Сделано: …
  - Следующий шаг: …
  - Статус: …
  ```

- **День** `operation/daily/<ГГГГ-ММ-ДД>.md`, `## Сессии`:

  ```markdown
  ### ЧЧ:ММ — [[projects/<slug>/<slug>]] (итог)
  - Сделано: …
  - Следующий шаг: …
  - Статус: …
  ```

  Расходится с атомом — покажи пару «как записано / как есть», не правь молча.
- Статус `готово` / `отложено` — обнови `status` во frontmatter карточки проекта.

## CLOSE-7. Карта проектов

`CLAUDE.md`: строка проекта — статус, «Последняя сессия» = сегодня, «Следующий шаг» =
зафиксированный. Правится только блок между маркерами.

## CLOSE-8. Мост между чатами

Работа продолжится в новом чате — предложи записать
`.exocortex/memory/<агент>/session-handoff-{session_id}.md` (формат — MID-6). Не предлагай, если
сессия закрыта как `готово`.

## CLOSE-9. Показать итог

Покажи TL;DR, обновлённую карту проектов и — если он есть — промпт на продолжение.
