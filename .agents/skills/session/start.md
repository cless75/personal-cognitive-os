# Фаза START — начать сессию

Роутер и инварианты (шаг 0 «реальное время», подтверждение правок) — [SKILL.md](SKILL.md).

## START-1. Проект

(AskUserQuestion) Подтяни список из карты проектов `CLAUDE.md` (или из `projects/*/`) и предложи
выбором. Проекта ещё нет — предложи `/new-project`.

## START-2. Цель сессии

(короткий текст) **«Что хочешь получить из этой сессии?»** — одно предложение.

Цель обязательна: без неё чекпоинту (MID) не с чем сверяться, а итогу нечего отражать. Если
владелец не хочет её формулировать — запиши в атом `— (пропуск; сверка по цели проекта)` и
дальше сверяйся с целью проекта.

## START-3. Атом = Session Note

Создай `operation/sessions/S{ГГГГММДД}T{ЧЧММ}-{slug}.md` из шаблона в
`operation/sessions/README.md`:

- frontmatter: `session_id / when / where / project / mode: ispolnenie / source / produced: []`
  + `Status: "🔵 Активна"`, `Active: true`;
- тело — skeleton секций, в «Цель» — формулировка из START-2;
- `{slug}` — латиница kebab-case, до 40 символов.

*Слой опционален:* для микро-действия на пару минут атом можно пропустить — тогда сессия живёт
только строкой в дне.

## START-4. Отметки

- **Карточка проекта** `projects/<slug>/<slug>.md`, внутри `<!-- sessions:start -->…<!-- sessions:end -->`:

  ```markdown
  ### <ГГГГ-ММ-ДД ЧЧ:ММ> — старт
  - Цель: <цель>
  - Сессия: [[sessions/S…]]
  ```

- **День** `operation/daily/<ГГГГ-ММ-ДД>.md` (нет файла — создай из шаблона
  `operation/daily/README.md`), в `## Сессии`:

  ```markdown
  ### ЧЧ:ММ — [[projects/<slug>/<slug>]] (старт)
  - Цель: <цель>
  ```

## START-5. Карта проектов

`CLAUDE.md`: строка проекта — статус `active`, «Последняя сессия» = сегодня, «Следующий шаг» =
цель сессии. Правится **только** блок между маркерами.

## START-6. Подтверждение

Покажи: проект, цель, что будет записано и куда. После «да» — записывай и держи цель в фокусе:
на чекпоинте она станет мерой того, туда ли идёт работа.
