# Навык: сессия по проекту — роутер фаз

**Фазы (протоколы):** [start.md](start.md) · [mid.md](mid.md) · [close.md](close.md).
**Команды (проекции):** `/start-session` → START · `/checkpoint-session` → MID · `/close-session` → CLOSE.

Сессия — это эпизод работы, у которого есть начало, ход и итог. Знание производно от эпизодов:
карточка концепта помнит, из какой сессии родилась. Поэтому сессия фиксируется, даже когда
кажется, что «и так помню».

## Слои: что где живёт

| Слой | Файл | Объём |
|------|------|-------|
| 1. День | `operation/daily/ГГГГ-ММ-ДД.md` § `## Сессии` | 1 строка на событие |
| 2. Атом = Session Note ⚡ | `operation/sessions/S{ГГГГММДД}T{ЧЧММ}-{slug}.md` | полно |
| 3. Карточка проекта | `projects/<slug>/<slug>.md`, блок `<!-- sessions:start -->…` | 1–3 строки |
| 4. Карта проектов | `CLAUDE.md`, блок между маркерами | 1 строка таблицы |
| 5. Мост между чатами (handoff) | `.exocortex/memory/<агент>/session-handoff-{session_id}.md` | 2–3 итога + 1–3 шага |

**Правило распределения.** Полное содержание — **только в атоме**. День получает строку,
карточка проекта — строку, карта проектов — статус, мост — сжатие для продолжения. Один и тот
же текст не копируется в два места: копии расходятся за часы.

## Шаг 0 (для всех фаз): реальное время

Перед любым штампом `ЧЧ:ММ` — спроси время у системы (`date +%H:%M` в bash, `Get-Date -Format HH:mm`
в PowerShell). **Не выдумывай время и не бери его из контекста разговора.** Нет доступа к оболочке —
спроси владельца.

## Маршрутизация фаз

**START** → [start.md](start.md) — «начинаем», «работаем над <проектом>», «старт сессии»,
`/start-session`.

**MID** → [mid.md](mid.md) — работа идёт, фиксируем состояние: «промежуточный итог», «чекпоинт»,
«зафиксируй прогресс», «пока не закрываем», `/checkpoint-session`.

**CLOSE** → [close.md](close.md) — «итог», «закрываем сессию», «заверши работу», `/close-session`.

Фраза «зафиксируй сессию» без уточнения: если в дне есть открытая сессия и владелец принёс
перечень сделанного — это CLOSE; если сказано «промежуточно» или «продолжаем» — MID; иначе задай
**один** вопрос: «старт, промежуточный чекпоинт или итог?»

## Инварианты

- **Чистый Markdown.** Ни одного обязательного плагина: файлы должны читаться после копирования
  на другую машину.
- **Ссылки** — относительные или `[[wikilink]]`.
- **Правки — после подтверждения.** Покажи, что именно запишешь и куда; пиши после «да».
- **Расхождение не чинить молча.** Если запись в дне или карточке не сходится с атомом — покажи
  пару «как записано / как есть» и жди решения владельца.
- **Диалог — через выбор вариантов** (AskUserQuestion), а не свободным текстом, где выбор конечен.
- В Base режим сессии один — ⚙️ Исполнение; поле `mode: ispolnenie` фиксировано, вопрос не задаётся.

## Выход

Эпизод работы, который можно продолжить после любого обрыва: атом с целью, ходом и итогом; день и
карточка проекта знают о нём по строке; карта проектов актуальна.
